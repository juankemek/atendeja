# Atende Já

Site institucional da Atende Já, atendente virtual que responde e agenda clientes de salões de beleza e barbearias no WhatsApp e no Instagram.

## Estrutura

- `index.html`: a página inteira (HTML, CSS e JavaScript em um só arquivo)
- `assets/`: logo nas versões clara, escura, ícone e SVG

## Publicar na Vercel

1. Em vercel.com, clique em **Add New → Project** e importe este repositório.
2. Em **Framework Preset**, escolha **Other**. Não há build.
3. Clique em **Deploy**.
4. Em **Settings → Domains**, adicione `useatendeja.com.br` e siga as instruções de DNS.
